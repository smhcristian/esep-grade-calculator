# ESEP Grade Calculator

A simple Go library for calculating a student's final letter grade based on a weighted average of their assignments, exams, and essays. You must install Golang for the library to work.

Runtime requirements:
Golang 1.24+

Run unit tests:
```
cd grade_calculator/
go test ./...
```

Run unit tests with code coverage:
```
cd grade_calculator/
go test -coverprofile=coverage.txt ./...
```
